# Data Attribution and Use

The example catalog schema and locally generated evaluation data are derived
from **Amazon Reviews 2023**, published by McAuley Lab at UCSD.

- Project page: https://amazon-reviews-2023.github.io/
- Selected category: `Clothing_Shoes_and_Jewelry`
- Product join key: `parent_asin`
- Modality: text and structured product metadata only

The repository does not contain images, videos, account credentials, or private
user data. Large local catalog files are intentionally excluded from Git.

Users must follow the source dataset's applicable terms. This project does not
claim ownership of the underlying Amazon review or product content.
